# Changelog

All notable changes to wp-agent-skills will be documented in this file.

## [1.0.0] - 2026-06-27

### Added
- 11 WordPress agent skills: wp-architecture-description, wp-coding-standards, wp-developer-documentation, wp-image-to-blocks, wp-plugin-directory-compliance, wp-public-documentation, wp-qa-testing, wp-requirements-specification, wp-site-inventory, wp-ua-testing, wp-user-documentation
- OKF v0.1 frontmatter on all skill files: `type`, `tags`, `timestamp`, `resource`, `dependencies`
- `skills/index.md` — OKF bundle progressive disclosure file with markdown links to all 11 concepts
- `skills/log.md` — OKF chronological change log
- README updated with OKF format reference and Compend MCP discovery
